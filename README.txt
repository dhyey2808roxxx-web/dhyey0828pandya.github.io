DHYEY PANDYA PORTFOLIO - GITHUB UPLOAD

This folder contains the finished website.

To publish it in GitHub:
1. Open your portfolio repository on GitHub.
2. Choose Add file, then Upload files.
3. Upload everything inside this folder: index.html and the assets folder.
4. Commit the changes.
5. In the repository Settings, open Pages and ensure publishing is enabled from the main branch.

Important: upload both index.html and the assets folder. The Apple TV+ slides will not appear without the assets folder.
